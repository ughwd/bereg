# Берег — бронирование загородных домов (учебное демо)

**Тема:** загородные дома. Пользователь выбирает дом на схеме посёлка или в списке, задаёт число гостей и ночей, видит сумму и подтверждает учебную бронь.

## Как запустить

Проект написан на HTML, CSS и ванильном JavaScript с ES-модулями, без сборки и сервера.
ES-модули не работают при открытии файла двойным кликом (`file://`), поэтому нужен любой статический сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Либо опубликуйте папку на GitHub Pages: Settings, Pages, ветка `main`, корень репозитория.

## Структура

```
index.html        разметка
css/styles.css    оформление и адаптив
js/data.js        данные домов (одни и те же для списка и схемы)
js/storage.js     сохранение в localStorage
js/main.js        логика интерфейса
```

## Функции

- Схема посёлка (дорога, озеро, кнопки-домики) и список тех же 8 домов. Два дома занято изначально.
- Статусы «свободен», «выбран», «занят» отличаются подписью, значком и рамкой, а не только цветом. Занятый дом выбрать нельзя.
- Фильтры по числу гостей и максимальной цене, кнопка сброса. Список и схема фильтруются одновременно. Если фильтр скрыл выбранный дом, выбор сбрасывается с сообщением. Пустой результат показывает подсказку.
- Карточка дома, форма «гостей и ночей», сумма обновляется при вводе. Ночей от 1 до 30, гостей от 1 до вместимости. Ошибки показываются рядом с полем.
- Подтверждение создаёт одну бронь с номером. Защита от двойного нажатия. Дом становится занятым.
- «Мои брони»: список, отмена освобождает дом. Брони сохраняются в `localStorage` под одним ключом и восстанавливаются после обновления. Повреждённые данные или запрет хранилища показывают сообщение. Кнопка «Сбросить демо» с подтверждением.
- Работает с клавиатуры (все дома — кнопки, виден фокус, у полей есть подписи) и на телефоне.

## Ограничение

Учебное демо: бронирования сохраняются только в этом браузере. Сервера, платежей и регистрации нет, реальная бронь не оформляется.
